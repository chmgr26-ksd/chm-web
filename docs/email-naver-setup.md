# 네이버 메일로 이메일 알림 설정하기

CHM Web의 문의 접수 알림·비밀번호 재설정 메일은 SMTP로 발송됩니다. 네이버 메일을 발송 계정으로 쓰는 방법입니다.

> **핵심**: 네이버는 **"IMAP/SMTP 사용"을 먼저 켜야** 외부 앱에서 발송할 수 있습니다.
> (이걸 켜지 않으면 SMTP 로그인 자체가 실패합니다.)

---

## 1단계 — 네이버에서 SMTP 사용 켜기 (필수)

1. **네이버 메일** 접속 → 좌측 하단 **환경설정**(톱니바퀴 아이콘)
2. **POP3/IMAP 설정** 탭으로 이동
3. **IMAP/SMTP 사용**을 **"사용함"** 으로 선택하고 저장

---

## 2단계 — 비밀번호 준비

- **2단계 인증이 꺼져 있으면**: 네이버 로그인 비밀번호를 그대로 사용합니다.
- **2단계 인증이 켜져 있으면**: 일반 비밀번호로는 SMTP 로그인이 안 됩니다 → **애플리케이션 비밀번호**를 발급해 사용합니다.
  - 네이버 **내정보 → 보안설정 → 2단계 인증 → 애플리케이션 비밀번호** 에서 생성 → 복사

---

## 3단계 — 앱에 입력

**대시보드 → 알림 설정** 에서 다음을 입력합니다.

| 항목 | 값 |
|---|---|
| 문의 접수 알림 사용 | **켜기** |
| 수신 이메일 | 알림을 받을 주소 (비우면 관리자 전체에게 발송) |
| **SMTP 호스트** | `smtp.naver.com` |
| **포트** | `465` (SSL, 권장) 또는 `587` (STARTTLS) |
| **계정(사용자)** | 전체 이메일 — `아이디@naver.com` |
| **비밀번호** | 네이버 비밀번호 (2단계 인증이면 **애플리케이션 비밀번호**) |
| **발신 표시(선택)** | `CHM Group <아이디@naver.com>` |

입력 후 **저장 → "테스트 메일 발송"** 버튼으로 정상 발송을 확인합니다.
(비밀번호는 서버에서 AES-256-GCM으로 암호화되어 저장되며, 화면에 다시 표시되지 않습니다.)

> 포트에 따라 앱이 자동으로 처리합니다: **465 → SSL**, 그 외(587 등) → **STARTTLS**.

---

## 환경변수로 설정하기 (대안)

UI 대신 hPanel 환경변수로도 설정할 수 있습니다. (UI 설정이 있으면 UI가 우선합니다.)

| 이름 | 값 |
|---|---|
| `SMTP_HOST` | `smtp.naver.com` |
| `SMTP_PORT` | `465` |
| `SMTP_USER` | `아이디@naver.com` |
| `SMTP_PASS` | 네이버 비밀번호 또는 애플리케이션 비밀번호 |
| `SMTP_FROM` | `CHM Group <아이디@naver.com>` (선택) |
| `NOTIFY_EMAIL` | 수신자(선택, 미설정 시 관리자 전체) |

---

## 알아둘 점 / 문제 해결

- **발신 주소는 그 네이버 계정으로 고정됩니다.** 다른 주소로 "보낸 사람"을 위조해 보낼 수 없습니다. 발신 표시의 이메일은 로그인 계정과 같아야 하며, 이름만 "CHM Group" 등으로 표기할 수 있습니다.
- **발송 한도**: 네이버는 외부 SMTP 대량 발송을 제한합니다(하루 수백 통 수준). 관리자 알림·비밀번호 재설정 용도엔 충분하지만, 대량 발송엔 부적합합니다.
- **테스트 메일이 실패**하면:
  - **"IMAP/SMTP 사용"이 "사용함"인지 재확인** (가장 흔한 원인)
  - 2단계 인증인데 일반 비번을 넣은 경우 → **애플리케이션 비밀번호**로 교체
  - 계정(사용자)을 **전체 이메일**(`@naver.com` 포함)로 입력했는지 확인
  - 포트 `465`가 막히면 `587`로 바꿔 시도
  - 네이버가 "새로운 기기/위치 로그인"으로 차단했을 수 있으니, 네이버 로그인 알림·보안 메일을 확인
