# Gmail로 이메일 알림 설정하기

CHM Web의 문의 접수 알림은 SMTP로 메일을 보냅니다. Gmail을 발송 계정으로 쓰는 방법입니다.

> **핵심**: Gmail은 일반 로그인 비밀번호가 아니라 **"앱 비밀번호(App Password)"**를 써야 합니다.
> 구글이 일반 비밀번호를 이용한 외부 앱 로그인을 차단했기 때문입니다.

---

## 1단계 — Gmail 앱 비밀번호 발급

1. [Google 계정](https://myaccount.google.com) → **보안**
2. **2단계 인증(2-Step Verification)을 먼저 켭니다.** (이게 켜져 있어야 앱 비밀번호 메뉴가 나옵니다)
3. 다시 **보안 → 앱 비밀번호(App passwords)** — 검색창에 "앱 비밀번호"를 입력하면 빠르게 찾을 수 있습니다.
4. 앱 이름(예: `CHM Web`)을 입력하고 **생성** → **16자리 비밀번호**가 표시됩니다 → 공백 없이 복사합니다.

이 16자리가 아래 설정의 **비밀번호** 칸에 들어갑니다. (Gmail 로그인 비밀번호가 아닙니다.)

---

## 2단계 — 앱에 입력

**대시보드 → 알림 설정** 에서 다음을 입력합니다.

| 항목 | 값 |
|---|---|
| 문의 접수 알림 사용 | **켜기** |
| 수신 이메일 | 알림을 받을 주소 (비우면 관리자 전체에게 발송) |
| **SMTP 호스트** | `smtp.gmail.com` |
| **포트** | `465` (권장, SSL) 또는 `587` (STARTTLS) |
| **계정(사용자)** | 본인 Gmail 주소 — `yourname@gmail.com` |
| **비밀번호** | 1단계에서 발급한 **앱 비밀번호 16자** |
| **발신 표시(선택)** | `CHM Group <yourname@gmail.com>` |

입력 후 **저장 → "테스트 메일 발송"** 버튼으로 정상 발송을 확인합니다.
(비밀번호는 서버에서 AES-256-GCM으로 암호화되어 저장되며, 화면에 다시 표시되지 않습니다.)

> 포트에 따라 앱이 자동으로 처리합니다: **465 → SSL**, 그 외(587 등) → **STARTTLS**.

---

## 환경변수로 설정하기 (대안)

UI 대신 hPanel 환경변수로도 설정할 수 있습니다. (UI 설정이 있으면 UI가 우선합니다.)

| 이름 | 값 |
|---|---|
| `SMTP_HOST` | `smtp.gmail.com` |
| `SMTP_PORT` | `465` |
| `SMTP_USER` | `yourname@gmail.com` |
| `SMTP_PASS` | 앱 비밀번호 16자 |
| `SMTP_FROM` | `CHM Group <yourname@gmail.com>` (선택) |
| `NOTIFY_EMAIL` | 수신자(선택, 미설정 시 관리자 전체) |

---

## 알아둘 점 / 문제 해결

- **발신 주소는 그 Gmail 계정으로 고정됩니다.** Gmail은 임의의 다른 주소로 "보낸 사람"을 위조해 보낼 수 없습니다. 발신 표시의 이메일은 로그인한 Gmail과 같아야 하며, 이름만 "CHM Group" 등으로 표기할 수 있습니다.
- **발송 한도**: 무료 Gmail 하루 약 500통, Google Workspace 약 2,000통 — 관리자 알림 용도엔 충분합니다.
- **Google Workspace 계정**이면 조직 관리자가 앱 비밀번호를 막아뒀을 수 있습니다. 그 경우 관리자에게 허용을 요청하거나 개인 Gmail을 사용하세요.
- **테스트 메일이 실패**하면:
  - 앱 비밀번호를 다시 확인 (공백 없이 16자), 2단계 인증이 켜져 있는지 확인
  - 포트를 465 ↔ 587로 바꿔서 시도
  - 계정(사용자)이 전체 Gmail 주소인지 확인 (`@gmail.com` 포함)
- **전용 발송 계정**을 원하면(개인 메일과 분리) 새 Gmail을 하나 만들어 위 과정을 그대로 진행하세요.
